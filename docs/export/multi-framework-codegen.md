# Multi-Framework Code Export & Dev Mode

## Overview
Chigma provides direct code generation for modern frontend tech stacks:

1. **Semantic HTML5 & Vanilla CSS**: Complete self-contained single-file HTML bundle with CSS variables, auto-layout flexbox styling, and vanilla interactivity.
2. **React + TypeScript (Tailwind CSS)**: Idiomatic components with prop interfaces, Tailwind CSS utility classes, and state bindings.
3. **Next.js App Router**: Client-component compatible (`'use client';`) React templates ready for file-based routing.
4. **Dev Mode / Handoff Inspector**:
   - Live Box-model metrics (Width, Height, X, Y, Radii).
   - CSS Variables view (`var(--color-primary)`).
   - 1-click Copy button for rapid handoff from design to IDE.
