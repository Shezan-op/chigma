# Interactive Prototyping Runtime 2.0

## Overview
Chigma includes an isolated, stateful prototyping runtime that evaluates interactions without modifying the permanent document model during presentation.

## Features
- **Triggers**: `click`, `hover`, `mouseDown`, `afterDelay`, `variableChange`.
- **Actions**: `navigate`, `openOverlay`, `closeOverlay`, `swapComponentState`, `setVariable`, `toggleVariable`, `incrementVariable`, `scrollTo`, `back`, `url`.
- **Overlays**: Modals, Drawers, Dropdowns, and Bottom Sheets with customizable backdrops and close-on-click rules.
- **Session Variables**: Live numerical and boolean reactive state (e.g. cart counts, active tabs, dark mode toggle).
- **Debugger HUD**: Real-time event activity log and live variable inspection sidebar.
- **Device Frames**: MacBook Pro (1280×800), iPad Air (820×1180), iPhone 15 Pro (393×852), and Fullscreen Canvas.
