# Skill: Create SaaS Dashboard

## Description
Constructs a complete SaaS analytics dashboard layout including left sidebar navigation, top header bar, 3 KPI metric cards with subtle drop shadows, dual line and donut charts, and recent activity data table.

## Context Needed
- `pageId`: Target page.
- `title`: Dashboard application title.

## Execution Rules
1. Insert left navigation sidebar (220×760px).
2. Insert top header bar with search and avatar controls.
3. Add 3 KPI metric cards along a horizontal row with 8px/16px gaps.
4. Add line chart and donut chart side-by-side.
5. Add 5-column data table at the bottom.
