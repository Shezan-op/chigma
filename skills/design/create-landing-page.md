# Skill: Create Landing Page

## Description
Generates a high-converting, modern SaaS marketing landing page with navigation bar, hero banner, CTA pills, metric charts, and feature cards.

## Context Needed
- `pageId`: Active target page.
- `brandName`: Product or organization name.
- `theme`: Primary color token or preset.

## Execution Rules
1. Insert a 1200px container frame or layout header navbar at (100, 40).
2. Add a headline with 34px bold typography and muted subtitle copy.
3. Position primary and secondary CTA buttons with 50px pill corner radii.
4. Add a quarterly growth bar chart and multi-card feature grid.
5. Align all elements to the 8px grid.
