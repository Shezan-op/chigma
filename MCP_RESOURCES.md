# Chigma MCP Resources Reference

## Exposed Resource URIs

### `chigma://project/current`
- **MIME Type**: `application/json`
- **Description**: Current document metadata, active pages, token collections, and registered master component summaries.

### `chigma://design-system`
- **MIME Type**: `application/json`
- **Description**: Active design variables (Colors, Spacing, Typography) across Light and Dark modes.

### `chigma://components`
- **MIME Type**: `application/json`
- **Description**: Master component registry (`ComponentMaster[]`) with component IDs, variant keys, and property signatures.
