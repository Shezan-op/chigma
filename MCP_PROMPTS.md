# Chigma MCP Prompts Reference

## Exposed Prompts

### 1. `design-review`
- **Arguments**: None
- **Purpose**: Generates an exhaustive design review examining visual hierarchy, spacing token compliance, WCAG AA color contrast, touch targets (<44px), and consistency.

### 2. `create-saas-dashboard`
- **Arguments**: `theme` (`'light' | 'dark'`)
- **Purpose**: Synthesizes a full SaaS operations analytics dashboard with sidebar navigation, metric KPI cards, growth line charts, donut chart breakdowns, and recent activity data tables.

### 3. `make-responsive`
- **Arguments**: None
- **Purpose**: Evaluates container frames and applies responsive constraints (`left`, `center`, `right`, `left_right`, `scale`) for seamless multi-device breakpoint rendering.
